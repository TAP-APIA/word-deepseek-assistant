# DeepSeek 文档助手

一个运行在 Microsoft 365 **Word 桌面版**侧边栏的 Office 加载项：在编辑文档的同时与 DeepSeek 对话，并把回复直接写入当前文档。

## 主要功能

- **侧边栏对话**：无需切换窗口，在 Word 内与 DeepSeek 连续对话。
- **直连 DeepSeek API**：浏览器直接调用 DeepSeek 官方接口，无需本地服务，电脑上无任何常驻进程。
- **模型实时拉取**：自动从 DeepSeek API 获取当前可用模型（`deepseek-v4-flash` / `deepseek-v4-pro`），不内置过时的模型 ID。
- **思考过程展示**：模型的思考过程以可折叠区域实时展示，可随时展开或收起。
- **流式回复**：回复逐字实时显示，生成过程一目了然。
- **一键应用到文档**：可将回复替换当前选中内容，或插入光标处、文档开头、文档结尾。
- **只插入正文**：当回复用代码块包裹正文时，应用时只写入代码块内的内容，修改说明不会混入文档。
- **附带文档上下文**：可勾选附带当前选中内容或全文，让模型基于文档实际内容回答，不会凭空编造。
- **历史对话**：自动保存对话记录，支持在侧边栏展开列表切换、恢复历史对话。
- **快捷发送**：回车直接发送，Shift+回车换行。
- **隐私友好**：API Key 仅保存在本机浏览器本地存储中，请求直接发送给 DeepSeek 官方，不经过任何第三方服务器。

## 使用环境

- Microsoft 365 桌面版 Word（Windows），无需安装 Node.js 或运行任何本地服务。
